A full-stack LinkedIn clone built with **React.js, Tailwind CSS, Node.js, Express, and MongoDB**.  
The app allows users to **register, login, view posts, create posts, and manage their profile**, with a LinkedIn-style homepage layout.

---

## 🛠 Features

### Frontend
- React.js with functional components
- Tailwind CSS for responsive UI
- React Router v6 for routing
- Navbar with Home, Jobs, Notifications, and Profile links
- Feed with posts and post creation
- Profile page with user info

### Backend
- Node.js + Express.js API
- MongoDB database for user and post storage
- JWT authentication
- Protected routes
